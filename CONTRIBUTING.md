# Contributing

Thanks for helping grow framesmith. New templates, engine effects, and fixes are all welcome.

1. Fork and clone, then `pip install -r requirements.txt` and install `ffmpeg`.
2. Follow [AGENTS.md](AGENTS.md). It covers the invariants and how to add a skill.
3. Run `python3 tools/validate.py` before opening a PR.
4. In the PR, include a GIF or contact sheet of what your template renders.

Please use fictional brands in examples, and only commit imagery you have the rights to (your own renders, or AI generations whose terms allow it).
