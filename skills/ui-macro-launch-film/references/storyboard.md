# Storyboard: ui-macro-launch-film

The reference is an 87 s, 1280×720, 24 fps Instagram reel for a workspace app, with music only and 38 detected cuts (average 2.3 s). The palette is 93 % white, with ink type and colour only in UI states. This template compresses it to 57.5 s.
